After creating the GitHub repository, run these commands:

cd d:\GreekWaveTech
git push -u origin main

This will upload your GreekWave Technologies website to:
https://github.com/revs-96/greekwave-technologies

Then you can deploy to Vercel:
1. Go to https://vercel.com
2. Sign in with GitHub
3. New Project → Select greekwave-technologies
4. Deploy!
